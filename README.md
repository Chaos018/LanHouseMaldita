# Lan House Maldita (v0.1 - Etapa 1)

Como gerar o APK:
1. Abra esta pasta no Android Studio (File > Open) e espere o Gradle sincronizar.
2. Build > Build Bundle(s) / APK(s) > Build APK(s).
3. O APK fica em app/build/outputs/apk/debug/app-debug.apk. Copie para o celular e instale.

Controles: lado esquerdo da tela = analógico (arraste); lado direito = atacar (segure).
